# CMPSC-123-Project
Number Guessing Game

Project description:
This project is a terminal-based Number Guessing Game where the computer generates
a random number and the player attempts to guess it. After each guess, the program
provides feedback indicating whether the guess is too high, too low, or correct.
The game continues until the correct number is guessed or the player runs out
of attempts (depending on difficulty level).

Instructions to run the program:
First choose choose a difficulty level:
1. Easy (1-50 with unlimited guesses)
2. Medium (1-100 with 10 guesses)
3. Hard (1-200 with 5 guesses)

Next, play the game! Guess any positive integer and use the feedback to help you
get closer to the correct number.

The game ends when you guess the correct number or when you run out of attempts.
If you wish to play again, enter 'y' when prompted. If not, enter 'n'
